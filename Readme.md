# TiendaAccesorios

Este proyecto es una página web desarrollada para el curso de Front-end JS. -Entrega Final-

## Descripción

TiendaAccesorios es una tienda online de accesorios para lectores, donde se pueden encontrar productos como marcapáginas, luces de lectura y fundas para libros. Además consume la API de DummyJSON para mostrar productos de muebles y decoración del hogar.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- Grid
- Media Queries
- JavaScript (Fetch API, localStorage)
- Formspree (formulario de contacto)

## Funcionalidades

- Navegación interna
- Diseño responsivo
- Sección de productos en cards
- Reseñas organizadas con Grid
- Productos traídos desde una API externa (DummyJSON)
- Carrito de compras con localStorage (agregar, editar cantidad, eliminar, vaciar)
- Simulación de compra
- Formulario funcional de contacto con validación
- Metaetiquetas para SEO
