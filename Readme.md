# TiendaAccesorios

Este proyecto es una página web desarrollada para el curso de Front-end JS.

## Descripción

TiendaAccesorios es una tienda online de accesorios para lectores, donde se pueden encontrar productos como marcapáginas, luces de lectura y fundas para libros.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- Grid
- Formspree (formulario de contacto)

## Funcionalidades

- Navegación interna
- Diseño responsivo
- Sección de productos en cards
- Reseñas organizadas con Grid
- Formulario funcional de contacto
